# начало конца: пресейв-сайт

Мозг дрозофилы подключили к пресейву. Муха стоит на столе и тянется к кнопке «Пресейв» на странице BandLink. Играет отрывок: подводка к припеву. Перед самой фразой припева последний удар уходит в реверб и обрывается. На обрыве появляется «SIGNAL LOST»: муха не дотянулась, нажми за неё.

## Ночь релиза

- До 22:00 1 октября (мск) всё как было: муха тянется к пресейву.
- В 22:00, за два часа до релиза, муха умирает. Если сайт открыт, это видно: дёргается, жужжит, шатается и падает на спину, лапки дёргаются и поджимаются. Если открыть позже, она уже лежит. Картинка становится чёрно-белой (фильтр щёлкает в момент падения), в правом верхнем углу траурная лента. HUD показывает `FLATLINE`, 0.00M и плоскую линию, отсчёт до 00:00 идёт дальше. Строка: «муха померла за два часа до релиза. поставь пресейв за неё.», после пресейва «готово. муха не узнает.».
- В 00:00 кнопка становится «слушать» и ведёт на `LISTEN` в `dist/app.js` (сейчас это та же `band.link/startend` с UTM: BandLink сам превращает пресейв в страницу релиза; если у релиза будет отдельный смартлинк, поменять там). Муха лежит, строка «муха померла за два часа до релиза. послушай трек за неё.». Кто нажал «слушать» и вернулся, видит, как она переворачивается, встаёт и потирает лапки, цвет возвращается: «готово. муха слушает.». Это до конца визита (sessionStorage).
- Время смерти: `DEATH` в `dist/app.js`. Тексты строки: `render()` там же.

## Что где

- `dist/` лежит всё, что уходит на хостинг, и больше ничего.
  - `index.html`: разметка, OG-теги, шрифты.
  - `style.css`: интерфейс, телефонная раскладка, состояния.
  - `app.js`: звук, отсчёт, HUD, кнопки, UTM, шаринг. Не зависит от 3D: если WebGL не поднимется, кнопка пресейва, звук и отсчёт всё равно работают.
  - `scene.js`: 3D-сцена (пиксельный пост-процесс, комната, дождь, город, монитор со страницей BandLink, камера, анимация мухи, «голова»).
  - `fly.js`: модель мухи и риг (IK для шести лап).
  - `thoughts.js`: что плавает в голове. Список можно править руками.
  - `assets/replay.mp3` и `assets/replay.json`: отрывок и его огибающая, по которой двигаются муха и HUD.
- `tools/make_excerpt.py`: нарезка отрывка из мастера по сетке тактов, с реверб-хвостом.
- `excerpts/`: варианты отрывков для сравнения на слух. На хостинг не попадают.

## Отрывок

Сетка мастера: 125 BPM, такт 1,92 с, первая сильная доля на 0,26 с.

| вариант | что внутри | тайминг мастера |
| --- | --- | --- |
| **E (стоит на сайте)** | подводка, обрыв в паузе перед фразой припева → реверб, обрыв | 0:30.50–0:44.60 + 2,2 с хвоста |
| D | подводка → первый удар припева → реверб | 0:30.50–0:46.82 + 2,2 с хвоста |
| C | то же без реверба, сухой обрыв | 0:30.50–0:46.82 |
| A | подводка и половина припева | 0:30.98–0:54.02 |
| B | куплет, обрыв ровно перед припевом | 0:15.62–0:46.34 |

Пересобрать отрывок (мастер в проект не копируется):

```bash
python3 tools/make_excerpt.py "/путь/к/мастеру.mp3" 15.75 23.0938 dist/assets 0.35 2.2
mv dist/assets/excerpt.mp3 dist/assets/replay.mp3 && mv dist/assets/excerpt.json dist/assets/replay.json
```

Аргументы: начальный такт, конечный такт (дробная часть означает доли), папка, fade-in в секундах, длина реверб-хвоста. Громкость и «жёсткость» хвоста задаются в `render_with_tail`: `irgain`, компрессор и нарастание `0.75` (дБ/с ÷ 20).

## Перед публикацией

1. Сайт живёт на GitHub Pages с доменом http://anomatver.ru/ (старый https://thematver.github.io/fly/ перенаправляет туда вместе с UTM). Деплой только через Actions: если в настройках Pages что-то менять (домен и т. п.), GitHub может запустить свою Jekyll-сборку корня репозитория, и вместо сайта откроется README. Тогда перезапустить workflow `pages`. Раньше было: https://thematver.github.io/fly/ (репозиторий https://github.com/thematver/fly, выкладка сама по пушу в `main`, см. `.github/workflows/pages.yml`). Когда привяжешь домен (Settings → Pages → Custom domain), замени `https://thematver.github.io/fly/` в `dist/index.html` на новый адрес (canonical, og:url, og:image, twitter:image). Без абсолютного адреса Telegram и VK не покажут картинку в превью.
2. Удалить с хостинга старый `assets/excerpt.mp3`, если он туда уже попадал: в нём припев целиком.
3. Проверить, что сайт открывается из России без VPN на мобильном интернете (МТС, Билайн, МегаФон, Т2). Хостинги за Cloudflare в РФ сейчас режут. Надёжнее GitHub Pages, Yandex Object Storage или российский VPS.
4. После каждой выкладки обновить превью ссылки: в Telegram через @WebpageBot, во ВКонтакте через `pages.clearCache`.
5. По желанию: вписать номер счётчика Яндекс Метрики в `METRIKA_ID` в `dist/app.js`. Цели: `sound_on`, `presave_click`, `listen_click` (после релиза), `share`.

## Режимы для проверки и съёмки

- `?state=lost`: сразу финальный кадр «не дотянулась».
- `?state=pressed`: муха нажимает кнопку (так сайт выглядит, когда человек вернулся после пресейва).
- `?state=live`: как сайт будет выглядеть после 2 октября. Кнопка станет «слушать», а 2 октября в 00:00 по Москве это переключится само.
- `?state=dead`: муха уже мёртвая (как с 22:00).
- `?at=21:59:50`: часы сайта идут с этого момента (московское время; до полудня значит 2 октября, после полудня 1 октября; можно и полную дату `2026-10-01T21:59:50+03:00`). Так видно смерть в 22:00 и переход в 00:00. Для ролика: `?rec&at=21:59:55`.
- `?rec`: чистый кадр для записи вертикальных роликов, без кнопок.
- `?poster`: кадр для картинки превью 1200×630.
- `?mute`: без звука.
